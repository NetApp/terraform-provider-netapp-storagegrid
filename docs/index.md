# netapp-storagegrid Provider

Use the NetApp StorageGRID provider to manage StorageGRID with the Grid Management API and the Tenant Management API.
You must configure the provider with the proper credentials before you can use it.

Use the navigation to the left to read about the available resources and data sources.

To learn the basics of Terraform using this provider, follow the [getting started guide](guides/getting-started).

## Grid and tenant connection profiles

A connection profile defines how to reach and sign in to StorageGRID. Resources and data sources select a profile with
`cx_profile_name`.

* A profile without `account_id` signs in to the grid, and uses the Grid Management API.
  It is used by the resources and data sources whose name starts with `grid_`, for instance `netapp-storagegrid_grid_product_version`.
* A profile with the `account_id` of a tenant signs in to this tenant, and uses the Tenant Management API.
  It is used by the resources and data sources whose name starts with `org_`.

## Supported Platforms

* StorageGRID with the management API v4 (StorageGRID 11.8 or later), or v3 (earlier releases). The provider selects the version of the API from the version of StorageGRID, `api_version` of the connection profile can force it.
* The provider only connects with HTTPS.

## Example Usage

```terraform
terraform {
  required_providers {
    netapp-storagegrid = {
      source  = "NetApp/netapp-storagegrid"
      version = "0.1.0"
    }
  }
}

provider "netapp-storagegrid" {
  # A connection profile defines how to interface with a StorageGRID system.
  # At least one is required.
  connection_profiles = [
    {
      # A profile without account_id signs in to the grid, and uses the Grid Management API.
      # It is used by the grid_ resources and data sources.
      name           = "grid1"
      hostname       = var.hostname
      username       = var.username
      password       = var.password
      validate_certs = var.validate_certs
    },
    {
      # A profile with the account_id of a tenant signs in to this tenant, and uses the Tenant Management API.
      # It is used by the org_ resources and data sources.
      name           = "tenant1"
      hostname       = var.hostname
      username       = var.tenant_username
      password       = var.tenant_password
      account_id     = var.account_id
      validate_certs = var.validate_certs
    },
  ]
}
```

### Nested Schema for `connection_profiles`

Required:

- `hostname` (String) IP address or FQDN of an Admin Node, or of a load balancer endpoint for the management interface. A port can be added, as in `grid.example.com:8443`.
- `name` (String) Profile name
- `password` (String, Sensitive) Password for username
- `username` (String) User name. A local or a federated user of the grid, or of the tenant when `account_id` is set.

Optional:

- `account_id` (String) ID of a tenant account. When set, the profile signs in to the tenant and uses the Tenant Management API. When not set, the profile signs in to the grid and uses the Grid Management API.
- `api_version` (String) Version of the management API to use, `v3` or `v4`. By default, `v4` is used with StorageGRID 11.8 or later, and `v3` with earlier releases.
- `ca_cert_file` (String) Path to a CA certificate file, to validate the certificate of StorageGRID.
- `validate_certs` (Boolean) Whether to enforce SSL certificate validation, defaults to true.
